# 高股息股票预测算法

## 项目概述

本项目旨在通过机器学习方法，对高股息股票进行识别和预测。通过分析高股息基金的持仓情况，结合财务数据和量价数据，构建了一个能够识别高股息股票特征的模型系统。该项目包含两个版本（v1和v2）的Jupyter笔记本，分别实现了不同的模型优化和特征工程方法。

## 功能特点

- **数据采集**：从Wind金融数据库中获取高股息基金数据和基金持仓信息
- **特征工程**：基于财务报表、现金流量表、资产负债表等多种数据源，构建综合特征集
- **模型训练**：使用XGBoost和决策树算法构建分类模型
- **模型评估**：采用Recall、Precision、F1-Score等指标评估模型性能
- **特征重要性分析**：使用SHAP值分析特征对预测结果的贡献程度
- **可视化分析**：包含混淆矩阵、特征重要性等可视化分析
- 
## 数据源

- **高股息基金数据**：从Wind数据库的`ChinaMutualFundDescription`表获取
- **基金持股信息**：从`ChinaMutualFundStockPortfolio`表获取
- **财务数据**：从多个财务相关表获取，包括资产负债表、利润表、现金流量表等
- **量价数据**：获取股票的交易量价数据

## 项目流程

1. **数据采集**：获取高股息基金列表及其持仓股票信息
2. **数据预处理**：合并不同来源的数据，处理缺失值，构建标签集
3. **特征工程**：构建财务特征和量价特征
4. **数据集划分**：将数据集划分为训练集和测试集
5. **模型训练**：训练XGBoost和决策树模型
6. **模型评估**：使用多种评估指标评估模型性能
7. **特征重要性分析**：分析对预测结果影响最大的特征

## 使用方法

1. 环境zcenv

2按顺序执行Jupyter笔记本中的单元格：
   - `high_dividend_v1.ipynb` - 第一版算法实现
   - `high_dividend_v2.ipynb` - 优化后的算法实现


## 注意事项

- 在进行特征工程时，应注意处理缺失值和异常值，以提高模型的稳定性和准确性
