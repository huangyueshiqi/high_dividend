# 高股息股票分析工具 - 项目结构说明

## 主要模块

### 1. 数据获取模块
* `get_ggx_hold.py` - 从数据库获取高股息基金的持仓信息

### 2. 数据处理模块
* `process.py` - 基础数据处理功能
* `util.ipynb` - 实用工具函数集合

### 3. 数据分析模块
* `High_dividend_eda.py` - 高股息数据探索性分析
* `high_dividend_analyze.ipynb` - 高股息分析详细过程
* `high_dividend_v1.ipynb` - 高股息分析初版

### 4. 模型构建模块
* `High_dividend_model.py` - 高股息预测模型实现
* `stockpool_predict.py` - 股票池预测功能

### 5. 数据文件
* Excel文件 - 基金持仓和交易数据
* CSV文件 - 处理后的测试数据

## 数据流向

1. 数据获取：从Oracle数据库获取基金和股票信息
2. 数据预处理：清洗、转换和规范化数据
3. 特征工程：构建预测模型所需的特征
4. 模型训练：使用XGBoost等算法训练预测模型
5. 预测评估：评估模型性能并生成预测结果

## 目录组织

```
cla_analysis/
├── README.md                 # 项目说明文件
├── requirements.txt          # 依赖包列表
├── 项目结构说明.md            # 本文件
├── process.py                # 数据预处理工具
├── get_ggx_hold.py           # 高股息基金持仓获取
├── High_dividend_eda.py      # 高股息数据探索分析
├── High_dividend_model.py    # 高股息预测模型
├── stockpool_predict.py      # 股票池预测功能
├── util.ipynb                # 工具函数集合
├── high_dividend_analyze.ipynb  # 分析笔记本
└── data/                     # 数据文件(可能不存在，代码中引用)
    ├── fund/                 # 基金相关数据
    └── month/                # 按月份组织的数据
```

## 使用流程建议

1. 先运行 `get_ggx_hold.py` 获取基金持仓数据
2. 使用 `High_dividend_eda.py` 进行数据探索
3. 根据需要修改 `High_dividend_model.py` 中的模型参数
4. 运行 `stockpool_predict.py` 生成预测结果

## 代码依赖关系

* `stockpool_predict.py` 依赖于 `High_dividend_model.py` 的模型
* `High_dividend_eda.py` 为 `High_dividend_model.py` 提供数据支持
* 所有模块都依赖于 `process.py` 的基础功能
